Foto kendaraan ADDON untuk semua script (STNK, cityhall, garasi f_phone, mekanik).
Kendaraan bawaan GTA tidak perlu foto di sini, otomatis memakai gambar docs.fivem.net.

Nama file  : <nama spawn>.webp   (contoh: civic22.webp)
Sudut foto : 3/4 dari depan, moncong menghadap ke kiri, latar transparan atau polos
Ukuran     : sekitar 640x360

Cara menambah:
- Manual   : taruh file .webp di folder ini
- Otomatis : admin ketik /fotokendaraan <model> (atau "addon") di dalam game
Lalu jalankan: ensure f_vehimages
