06

Aturan supaya tetap ringan

Berlaku untuk semua NUI yang pakai base ini

Tanpa blur CSS

backdrop-filter tidak memburamkan dunia game di NUI, cuma makan GPU. Transparansi pakai rgba. Kalau mau blur, pakai screenblur dari Lua seperti ox_lib patch.

Font lokal

Inter woff2 (≈100 KB) disimpan di resource base, bukan Google Fonts, supaya tidak tergantung internet & tidak ada delay.

Animasi seperlunya

Cuma opacity/transform, ≤ 200 ms. Tidak ada animasi berulang saat menu diam (kecuali spinner loading).

Tutup = hilang

Saat menu ditutup pakai display:none, body transparan, tidak ada interval JS yang jalan.

Vanilla JS

Menu biasa tanpa React/Vue. Ikon pakai SVG sprite inline, tanpa icon font / library.

Satu sumber gaya

Token & komponen di satu base.css; tiap script cukup tambah CSS layout sendiri. Ganti aksen/transparansi sekali, semua ikut.
